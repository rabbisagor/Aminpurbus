# AMINPUR BUS SIMULATOR (আমিনপুর বাস সিমুলেটর)
**পাবনা জেলা, বাংলাদেশ (Pabna District, Bangladesh)**

---

## 🚌 ভূমিকা (Overview)
**আমিনপুর বাস সিমুলেটর (Aminpur Bus Simulator)** হলো পাবনা জেলার আমিনপুর, কাশীনাথপুর, ঢালারচর এবং কাজীরহাট ফেরিঘাট অঞ্চলের বাস্তব গ্রামীণ সড়ক নেটওয়ার্ক ভিত্তিক একটি থ্রি-ডি (3D) বাস ড্রাইভিং ও সিমুলেশন গেম। খেলোয়াড়রা ঐতিহ্যবাহী বাংলাদেশি লোকাল বাস এবং আন্তঃজেলা চেয়ার কোচ চালিয়ে হাটবাজার, নদীঘাট ও গ্রামীণ জনপদে যাত্রী পরিবহন করতে পারেন।

গেমটি সম্পূর্ণ ক্লায়েন্ট-সাইড **React**, **TypeScript**, **Vite** এবং **Three.js** দিয়ে নির্মিত। এতে কোনো পেইড এপিআই বা এক্সটার্নাল সার্ভারের প্রয়োজন নেই এবং এটি মোবাইল ও ডেস্কটপ উভয় ডিভাইসেই সাবলীলভাবে চলে।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **প্রামাণ্য গ্রামীণ পরিবেশ (Authentic Bangladeshi Rural World):**
   - সবুজ ধানক্ষেত, পুকুর, তালগাছ, নারিকেল গাছ এবং শতবর্ষী ছায়াঘেরা বটবৃক্ষ।
   - টিনের দোচালা গ্রামীণ ঘর, মুদি দোকান, কালাম ভাইয়ের চায়ের টং (চা স্টল), এবং কেন্দ্রীয় জামে মসজিদ।
   - বাদলপুর আর্চ সংযোগ সেতু ও ঢালারচর পদ্মা-যমুনা নদীর সংযোগ পথ।
   - বাংলা মাইলস্টোন ও যাত্রী ছাউনি।

2. **বাস ও গ্যারেজ ব্যবস্থা (3 Distinct Bus Configurations):**
   - **আমিনপুর লোকাল এক্সপ্রেস (Aminpur Local Express):** ছাদের মালামাল ক্যারিয়ার ও বর্ণিল লোকাল বাস আর্টসহ টেকসই গ্রামীণ বাস।
   - **পাবনা ডিলাক্স আন্তঃজেলা (Pabna Deluxe Coach):** হাইওয়ে চেয়ার কোচ, আধুনিক অ্যারোডাইনামিক বডি ও উন্নত ব্রেকিং।
   - **পদ্মা সেতু রয়্যাল প্রিমিয়াম (Padma Royal Luxury Coach):** বিলাসবহুল হাইওয়ে কোচ, ডিজিটাল সাসপেনশন ও সর্বোচ্চ গতি।
   - **পারফরম্যান্স টিউনিং:** ইঞ্জিন, ব্রেক, হ্যান্ডলিং এবং ফুয়েল ট্যাংকের ৩-লেভেল আপগ্রেড।

3. **বাস্তব ড্রাইভিং ফিজিক্স (Driving Physics):**
   - মসৃণ এক্সিলারেশন, রিয়্যালিস্টিক টার্নিং স্টিয়ারিং, এবং গতির উপর নির্ভর করে স্টিয়ারিং সংবেদনশীলতা।
   - গিয়ার সিলেক্টর (D - ড্রাইভ, N - নিউট্রাল, R - রিভার্স, P - হ্যান্ডব্রেক)।
   - সাসপেনশন বডি-রোল ও পিচ মোশন।
   - ডিজিটাল স্পিডোমিটার (km/h) এবং আরপিএম মিটার।

4. **কৃত্রিম বুদ্ধিমত্তা ট্রাফিক (AI Traffic Simulation):**
   - বাংলাদেশের চিরচেনা সবুজ সিএনজি অটো-রিকশা (CNG 3-wheeler)।
   - নীল ও হলুদ ব্যাটারিচালিত ইজিবাইক / টমটম।
   - গ্রামীণ চান্দের গাড়ি ও পিকআপ ট্রাক।
   - সামনের গাড়ি ও বাসের দূরত্ব অনুযায়ী ট্রাফিকের গতি কমানো এবং থামার স্বয়ংক্রিয় ব্যবস্থা।

5. **যাত্রী ও মিশন ব্যবস্থা (Passenger Transportation):**
   - রুট অনুযায়ী টার্মিনাল বা বাস স্টপেজে পৌঁছানো।
   - বাস স্টপেজে থেমে "যাত্রী ওঠান / নামান" বাটনে চাপ দিয়ে যাত্রী বোর্ডিং।
   - লাইভ জিপিএস মিনিম্যাপ এবং রুটের দূরত্ব ট্র্যাকিং।
   - গন্তব্যে যাত্রী নামিয়ে ভাড়া (টাকা ৳), নিরাপদ ড্রাইভিং বোনাস ও XP অভিজ্ঞতা অর্জন।

6. **প্রসিডিউরাল অডিও ইঞ্জিন (Web Audio API Synthesizer):**
   - ডিজেল বাসের ইঞ্জিন আরপিএম শব্দ।
   - ঐতিহ্যবাহী মনমাতানো হাইড্রোলিক এয়ার হর্ন (Melodic Dual-Tone Air Horn)।
   - নিউম্যাটিক এয়ার ব্রেক রিলিজ হিস্ (`Psssshhhh`) সাউন্ড।
   - কোনো বাহ্যিক অডিও ফাইলের ব্যর্থতার ঝুঁকি ছাড়াই শতভাগ অফলাইনে সক্রিয়।

7. **দিন-রাত ও আবহাওয়া চক্র (Dynamic Weather & Time):**
   - সকালের সোনালী রোদ, দুপুরের উজ্জ্বল আলো, বিকেলের রক্তিম সূর্যাস্ত, এবং রাতের অন্ধকার।
   - রাতের জন্য কার্যকর হেডলাইট স্পটলাইট বিম।
   - বৃষ্টির কণা ও মনসুন বর্ষণ এফেক্ট।

## 🎮 নিয়ন্ত্রণ নির্দেশিকা (Controls)

### মোবাইল ডিভাইসে (Touch Controls)
- **সবুজ প্যাডেল:** এক্সিলারেটর / গ্যাস (চাপ দিয়ে ধরে রাখুন)
- **লাল প্যাডেল:** ব্রেক এবং রিভার্স
- **◀ ▶ বাটন:** বামে এবং ডানে স্টিয়ারিং ঘোরান
- **D / N / R বাটন:** গিয়ার পরিবর্তন
- **📯 বাটন:** হাইড্রোলিক এয়ার হর্ন বাজান
- **🚪 বাটন:** যাত্রী ছাউনিতে বাস থামালে দরজা খুলুন
- **📹 বাটন:** ক্যামেরা ভিউ বদলান (চেজ, ককপিট/ড্রাইভার সিট, বাম্পার, টপ-ভিউ)
- **💡 বাটন:** হেডলাইট অন/অফ

### কম্পিউটারে (Desktop Keyboard)
- `W` বা `↑` : এক্সিলারেটর (গতি বৃদ্ধি)
- `S` বা `↓` : ব্রেক / ব্যাক গিয়ার
- `A` / `D` বা `←` / `→` : স্টিয়ারিং বাঁয়ে ও ডানে
- `Space` : হ্যান্ডব্রেক
- `H` : হাইড্রোলিক হর্ন
- `E` : যাত্রী ওঠানো / নামানো
- `C` : ক্যামেরা ভিউ পরিবর্তন
- `L` : হেডলাইটের আলো অন/অফ
- `Esc` বা `P` : খেলা বিরতি (Pause)

## 🗺️ ম্যাপ ডাটা এডিটিং নির্দেশিকা (Map Editing Guide)

ম্যাপের রোড নেটওয়ার্ক এবং নতুন বাস স্টপ যুক্ত করা অত্যন্ত সহজ। সম্পূর্ণ ম্যাপ ডাটা ফাইলটি `src/data/mapData.ts`-এ অবস্থিত।

### নতুন রোড নোড যুক্ত করার নিয়ম:
```typescript
{
  id: 'node_notun_mor',
  x: 150, // মিটার (X অক্ষ)
  z: 220, // মিটার (Z অক্ষ)
  name: 'নতুন বাজার মোড়',
  isIntersection: true
}
```

### দুটি নোডের মধ্যে নতুন সড়ক সেগমেন্ট তৈরি:
```typescript
{
  id: 'seg_notun_road',
  fromNodeId: 'node_aminpur_terminal',
  toNodeId: 'node_notun_mor',
  width: 9,          // সড়কের প্রস্থ (মিটারে)
  lanes: 2,          // লেন সংখ্যা
  type: 'RURAL_PAVED', // 'HIGHWAY' | 'RURAL_PAVED' | 'VILLAGE_BRICK' | 'BRIDGE'
  speedLimit: 50     // গতিসীমা (কিমি/ঘণ্টা)
}
```

গেমে থাকা **ম্যাপ ইন্সপেক্টর** মোড স্বয়ংক্রিয়ভাবে `validateMapData()` চালিয়ে কোনো মিসিং নোড বা ত্রুটি রয়েছে কিনা তা প্রদর্শন করে।

## 🌐 গিটহাব ও ভার্সেল ডিপ্লয়মেন্ট (GitHub & Vercel Deployment)

### গিটহাবে আপলোড:
```bash
git init
git add .
git commit -m "Initial release of Aminpur Bus Simulator"
git branch -M main
git remote add origin https://github.com/your-username/aminpur-bus-simulator.git
git push -u origin main
```

### ভার্সেলে (Vercel) এক ক্লিকে ডিপ্লয়:
1. [vercel.com](https://vercel.com)-এ লগইন করুন।
2. **Add New Project** ক্লিক করে গিটহাব রিপোজিটরি নির্বাচন করুন।
3. Framework Preset হিসেবে **Vite** সিলেক্ট থাকবে।
4. রুট ডিরেক্টরিতে তৈরি থাকা `vercel.json` স্বয়ংক্রিয়ভাবে ক্লায়েন্ট-সাইড রাউটিং কনফিগার করে দেবে।
5. **Deploy** বাটনে ক্লিক করুন।
